# OMS - Order Management System

A comprehensive order management system for Pool Villa, built with FastAPI and PostgreSQL. This system manages room bookings, calculates prices based on day types (weekday, weekend, holidays), handles extra guest fees, and generates printable invoices.

## Features

- **Room Booking Management**: Create, view, update, and delete room bookings.
- **Dynamic Pricing Engine**: Calculates booking prices based on:
  - Room Type (3 Bedroom Pool Villa, 1 Bedroom Standard, etc)
  - Day Type (Monday-Thursday, Friday-Sunday, Holidays)
  - Number of Guests (including extra guest fees)
- **Invoicing**: Generates professional PDF invoices with:
  - Booking details
  - Slip booking
  - QR code for sharing
- **Role-Based Access Control**: 
  - **Admin**: Full access to all features.
  - **AI Agent**: Use n8n to communicate with customers and manage bookings. Generate invoices and send them to customers via Line.

## Tech Stack

- **Backend**: Python 3.13, FastAPI, Pydantic
- **Database**: PostgreSQL 16 (via SQLAlchemy + asyncpg)
- **PDF Generation**: ReportLab
- **QR Code**: qrcode
- **Authentication**: passlib, python-jose (JWT)
- **API Documentation**: Swagger UI (auto-generated by FastAPI)

## Environment Variables

Create a `.env` file in the project root (or use the provided template) with the following variables:

```env
# Database configuration
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=oms

# JWT configuration
SECRET_KEY=your-secret-key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

## API Endpoints

### Authentication

- `POST /auth/login`: User login
- `POST /auth/register`: Register new user
- `GET /auth/me`: Get current user profile

### Users

- `GET /users`: List all users
- `POST /users`: Create new user
- `GET /users/{user_id}`: Get user by ID
- `PUT /users/{user_id}`: Update user
- `DELETE /users/{user_id}`: Delete user

### Bookings

- `GET /bookings`: List all bookings
- `POST /bookings`: Create new booking
- `GET /bookings/{booking_id}`: Get booking details
- `PUT /bookings/{booking_id}`: Update booking
- `DELETE /bookings/{booking_id}`: Delete booking

### Reports

- `POST /reports/generate-invoice`: Generate PDF invoice
- `POST /reports/whatsapp-invoice`: Generate invoice and QR code for WhatsApp
